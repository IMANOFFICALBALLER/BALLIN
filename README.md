# BALLIN

## View the website

Open `index.html` in a browser. The page styling is in `styles.css`, and the small preview interaction is in `app.js`.

The README originally contained a saved webpage capture, including browser-extension markup. The capture did not include the original `Fix` action code, so that button reports that its behavior is unavailable in this preview.

The password check is performed in client-side JavaScript and is not secure authentication; anyone can inspect the page source to find or bypass it. Use a server-side authentication system if the page needs real access control.
